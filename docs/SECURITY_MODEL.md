# EnvNexus AI 权限与安全模型

## 默认边界

1. 启动时不读取注册表、PATH 或运行工具命令；只有用户点击扫描后才执行这些只读检查。启动只读取 App 数据目录中的上次扫描快照。启动后隐藏到托盘和普通托盘导航也不会扫描；托盘“手动重新扫描”是明确的用户操作。
2. 默认只允许写入 App 数据根目录、用户选择的工具目录和 HKCU 用户环境变量。
3. 系统级环境变量、HKLM、Windows 功能、Program Files 和其他用户目录均不在默认写入范围。
4. MVP 不提供“静默修改系统级配置”的后门。若某项操作必须提升权限，计划会标记为阻塞并说明原因。

“登录 Windows 后自动启动”默认关闭。只有用户在设置页明确启用并保存时，App 才写入当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\EnvNexus AI`；停用时删除同名值，不写 HKLM，不需要管理员权限。若配置文件保存失败，注册表值会恢复到保存前状态。

## 两阶段确认

所有持久化变更必须经过：

1. `preview`：生成确定的计划、差异、冲突、警告和环境快照指纹；
2. UI 显示计划并取得用户确认；工具 CMD 脚本调用同一个 `EnvNexus-AI.exe` 命令引擎，只有显式 `--yes` 才表示确认；
3. `apply(plan_id, fingerprint)`：重新检查指纹与计划有效期；
4. 先备份，再执行；
5. 验证失败自动回滚。

前端传入 `confirmed: true` 不能替代后端保存的计划，也不能构造任意环境变量写入。

`env-tools`、`<tool>-list` 和 `env-diagnose` 不会触发环境扫描，只读取内置定义或缓存快照。`env-scan` 必须由用户明确执行。`env-repair "<code>"` 默认也只生成预览，只有显式 `--yes` 才确认。工具脚本的变更命令与 GUI 使用相同的类型化 `OperationPlan`、确认令牌、环境指纹、备份和回滚服务，不提供绕过确认的备用执行路径。命令目录加入 HKCU PATH 也必须先生成差异计划并确认。

托盘里的非默认版本项也不是确认捷径。点击后只打开对应工具管理页并生成同一份默认版本切换计划；PATH、工具变量或工具链配置不会在用户确认前改变。

托盘诊断同样复用本地确定性规则。查看操作只读取缓存并生成本地建议；“生成诊断修复计划”只对扫描结果中标记为可修复的项目显示，仍需在 App 中核对 HKCU 差异、备份和回滚步骤后确认。不可修复、自定义别名取舍和系统级问题不会因托盘入口而自动执行。

## 下载与执行

- 只接受插件内声明的 HTTPS 官方主机。
- 重定向后的最终主机也要校验允许列表。
- 有官方 SHA-512/SHA-256/SHA-1 时必须校验；无官方校验值时 UI 显示供应链警告，并仍需经过同一计划确认；不会伪造校验值。
- 下载到 `.part` 文件，支持 HTTP Range；完成后原子重命名。
- 解压防止 `..`、绝对路径、NTFS 路径穿越和符号链接逃逸。
- 安装器参数由插件固定模板生成，不接受前端拼接命令。
- 版本探测子进程设置超时并捕获 stdout/stderr。操作 JSONL 只记录事件、时间、计划 ID 和相关路径，不记录令牌或完整命令输出。

## 删除与卸载

- App 只自动删除其安装清单拥有、且位于对应受管根目录内的路径。
- 外部发现的安装只提供诊断与官方卸载入口，不递归删除未知目录。
- 删除前解析规范化绝对路径，禁止卷根、数据根本身和宽泛父目录。
- 重要操作生成可恢复备份或回滚 journal。

## 凭据与网络

- AI API Key 只在用户明确填写并保存时收集，使用 Windows DPAPI 绑定当前 Windows 用户加密；配置 JSON 只保存厂商、URL、协议和模型，不保存明文密钥。
- API Key 不会返回给 WebView，也不会写入操作日志、诊断快照或 AI 提示词；删除密钥需用户明确操作。
- AI 基础 URL 必须为 HTTPS，不允许 URL 内嵌凭据、查询参数或片段。AI 客户端拒绝 HTTP 重定向，避免认证头被转发到其他主机。
- App 启动、加载快照、普通环境扫描和本地诊断均不调用 AI。用户必须在单条诊断上点击“AI 增强分析”并确认发送范围，才会把该诊断、相关安装版本/路径、版本管理器、机器架构与本地分析摘要发送到选定厂商。
- AI 输出没有执行权限，不能构造任意注册表键、命令或环境变量写入；实际修复仍由本地类型化计划、差异预览、备份和确认控制。
- 自定义别名、多管理器取舍、HKLM 和系统 PATH 不进入自动修复；本地一键修复只处理结果唯一且可验证的 HKCU 用户环境变更。
- 代理默认继承系统设置；若后续保存代理凭据，应使用 Windows Credential Manager。
- 当前官方版本清单不做离线持久缓存；下载包按工具缓存，复用前重新校验。

## 已知边界

- 已打开的进程保留旧环境块，广播环境变化不能改写现有终端。
- 第三方安装器可能产生自身的系统写入；调用前必须展示发布者、参数和已知副作用。
- 杀毒软件可能锁定下载或解压文件；事务需将此视为可恢复失败。
- 应用在进程被强制终止时不会自动执行崩溃恢复；未完成 journal 需依据日志人工检查，后续版本再提供恢复向导。
