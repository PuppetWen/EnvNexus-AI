# 已知限制

以下是 EnvNexus AI 0.1.7 的能力边界。本轮 CI7 功能检查和独立草稿资产签名验证已通过；公开发行与公开下载回读尚待完成，实际范围见[测试报告](TEST_REPORT.md)：

1. 仅构建和验证 Windows x64 MSVC 版本；没有 ARM64 包。
2. 不执行系统级环境变量、HKLM 或系统 PATH 修改。系统 PATH 遮蔽时切换计划会阻止执行。
3. 崩溃或断电后会保留安装 journal 和暂存/隔离目录，但尚无自动恢复向导；普通错误返回路径已实现回滚。
4. 官方版本清单已有持久化缓存，优先显示缓存并在过期后后台刷新；尚未使用 HTTP ETag 条件请求。没有缓存时仍需访问官方源，GitHub 官方发布页备用查询仅覆盖已实现的工具，不能保证所有上游离线可用。已下载发行包在复用前重新校验。
5. “升级”由安装新版本、切换、验证、再卸载旧版本组成，尚未合并为一个跨步骤原子计划。
6. Python 目录合并官网发布记录、历史归档和官方 CPython 版本标签，保留 0.9、1.x、Python 2、旧 Python 3、稳定版和预览版；源码标签或归档记录存在不代表该版本能在当前 Windows 运行，也不证明有或没有 Windows 包。完整 PythonCore ZIP 与 SHA-256 优先；受支持的历史 Wise EXE（Python 2.0–2.3）、MSI（Python 2.4 起）和 WiX Burn EXE（Python 3.5 起）静态提取已通过 CI7 十版本验收：`2.0.1`、`2.1.3`、`2.2.3`、`2.3.5`、`2.4.4`、`2.7.18`、`3.0.1`、`3.3.5`、`3.4.4`、`3.10.11`。仅源码、缺少 Windows 包或缺少可验证下载元数据时显示相应不可自动安装原因。Python 3.6 之前的运行时及随包 Tcl/Tk 要求 ASCII 安装目录，例如 `E:\Environment`；旧版路径拒绝检查及 Python `3.10.11` 中文、重音字符路径的安装与 pip/venv 验证均已通过。完整标准库和随包能力按实际发行组件保留：正式发行包中的 Python 2.7.9+ / 3.4+ 使用随包 wheel 离线初始化 pip，Python 3.3+ 保留内置 venv；早期 alpha 等预览版需单独区分组件边界。短私有工作目录和 pip/distutils 配置隔离不改变原发行包的能力；原包没有的功能不联网补装，也不伪造为已具备。尚未逐一验证全部历史版本、预览版、第三方包、原生扩展编译或 IDE 集成。历史 0.1.6 CI5（提交 `1ea507c`，[运行 38704689185](https://github.com/PuppetWen/EnvNexus-AI/actions/runs/38704689185)）的 15/15 安装、Python `3.15.0` 完整包及旧嵌入式安装修复结果保留在测试报告，不能扩展为本轮旧 MSI/EXE 的通过结论。Android SDK 仍仅覆盖 Command-line Tools，不含平台镜像、模拟器或 Android Studio；SDK、Gradle、Maven 探测依赖 runner 的现有 Java。
7. 外部安装只做发现、诊断和默认版本切换；EnvNexus AI 不直接调用厂商卸载器，也不会删除没有 EnvNexus AI 清单的目录。
8. 部分工具的官方 API 不提供可用校验值时，计划会显示供应链警告而不是伪造哈希；用户仍需确认。Python 历史条目没有有效校验元数据时阻止自动安装；官网仅提供 MD5 的包在计划中明确提示弱校验，它不等同于 SHA-256 或发行签名验证。正式企业策略仍可进一步限制允许的校验算法。
9. 数据目录更改在重启后生效，不自动迁移旧配置、缓存、日志或下载。
10. 外部 rustup 工具链的默认切换目前采用用户 PATH；EnvNexus AI 受管 Rust 使用隔离的 `CARGO_HOME`/`RUSTUP_HOME`。不会改写全局 rustup default。
11. 应用已支持检查、下载及确认安装签名更新，并为安装版和便携版提供失败回滚流程。当前仍未提供代理凭据 UI、下载并发设置、Windows Authenticode 代码签名或企业策略模板；更新包的 minisign 签名用于来源和完整性校验，不能替代 Windows 代码签名。
12. 0.1.7 CI7 已通过 15/15 类工具真实安装；ADB 真实 HKCU 激活、PATH/Android 变量及默认版本回读、原环境恢复通过，其余 14 类工具只验证切换计划。筛选排序、十个历史包安装、按版本区分 Python 能力、现代 Python 新装及旧嵌入式包原路径修复、用户环境保持和测试清理均通过。未完成真实开发机的 0.1.7 EXE/UI、Python 默认版本切换和全部历史版本卸载恢复验证。Python 修复后仍需单独确认 PATH 计划，系统 PATH 遮蔽仍会阻止用户级切换，不自动提升权限。0.1.6 的环境回读记录继续单独保留在[测试报告](TEST_REPORT.md)。
13. 没有使用用户的真实 OpenAI、Claude、Kimi、DeepSeek、GLM、Grok、Qwen 或 Gemini 凭据执行在线模型列表和推理测试；已验证协议适配、响应解析、URL 限制与 Windows DPAPI 往返，但真实账号权限、区域端点和计费需用户自行验证。
14. 某些厂商或兼容网关没有 `/models`、仅向特定工作空间开放，或返回非标准格式。UI 提供可编辑基础 URL 和手动模型 ID；这不等同于所有第三方服务都已兼容。
15. AI 增强分析只生成文本建议，不会自动执行模型建议，也不会把模型输出转换成环境修改计划。确定性的一键修复来自本地规则，只覆盖用户级、结果唯一且可备份回滚的问题；自定义别名、多版本管理器取舍和系统级问题仍需用户判断。
16. 工具命令脚本记录当前 `EnvNexus-AI.exe` 的绝对路径。移动便携版后必须在“命令说明”页重新生成脚本。命令目录可由用户选择，但不会自动加入 PATH；用户需先核对 HKCU PATH 差异并确认。
17. EnvNexus AI 当前把每个 .NET SDK ZIP 解压到独立版本目录，以便原子回滚、切换和卸载。多个版本可以共存，但选中的 `dotnet.exe --list-sdks` 只看到该隔离目录中的 SDK；它不是微软“多个 SDK 合并到同一 DOTNET_ROOT”布局，项目通过 `global.json` 自动选择另一个 EnvNexus AI 隔离版本前仍需先切换默认目录。
18. Python 历史目录使用两份批量发布/Windows 文件 API、完整运行时索引链、少量官方归档总表及 CPython 官方仓库的 Git v2 `ls-refs` 版本标签查询，避免逐版本额外请求或下载全部 pull refs；任一必需目录获取失败时不会将残缺结果冒充完整历史。Git v2 本轮网络样本的标签响应约 42 KB、包含 657 个版本标签；这些数值不代表固定目录规模、响应大小或性能承诺。网络、代理和上游限流仍影响冷查询与下载，尚未使用 HTTP 条件请求。本机 4 MiB 代理样本未证明并发下载提速，不能保证固定带宽或“4 倍速度”。[0.1.7 CI7](https://github.com/PuppetWen/EnvNexus-AI/actions/runs/39025514788) 的实时官方源、历史目录与安装、现代 Python 修复、15/15 类工具安装和 184 项 Rust / 62 项前端 / 4 项 Node 测试已通过；[独立草稿资产下载与签名验证](https://github.com/PuppetWen/EnvNexus-AI/actions/runs/39027005455)也已通过。公开发行和公开下载回读仍待完成。0.1.6 的 15 官方源、47 个完整 Python 运行时、CI5 整轮及六项公开资产回读通过记录保留在[测试报告](TEST_REPORT.md)，不作为本轮结果。
19. 五种语言目前覆盖导航、设置、常用操作与托盘菜单；工具名、官方版本信息、路径、诊断证据和可复制命令保留原文，以避免机器翻译改变技术含义或命令内容。
20. 工具图形用于产品识别，不表示 Python、Eclipse Adoptium、Google、Microsoft 或其他商标所有者对 EnvNexus AI 的认可。Android SDK、NDK 和 ADB 在 16–32 像素菜单尺寸下复用 Android 图形，App 内使用用途角标区分。
